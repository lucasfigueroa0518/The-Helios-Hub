## How we work (non-negotiable)

- Classify every change: cause/symptom · type · new stages · new AI calls.
- Prompt or rule changes need a pattern: 3+ of the last 10 posts. A false fact or a misleading photo is fixed after one case.
- Live AI runs need my OK. Estimate cost including retries and the $0.20 reserve the run budget keeps before each Claude call.
- Plain-language explanations. I make the calls.

## Pipeline
Feeds → Jev selection → Reporter → Writer → Editor → (Hook pass: separate track, not wired in) → Fact-checker → mechanical checks (M7) → design (photos + render + fit check) → preview.
- Claude stages run on Sonnet 5.5, high effort. Jev (TypeSafe) does yes/no scoring. The photo vision check runs on Haiku 4.5 (PHOTO_VISION_MODEL).
- Structured outputs throughout (submit_brief, submit_draft, submit_flags, submit_hooks), with IDs for facts, numbers and quotes, filled in by code.
- Daily cap is $2.00 (spec ceiling $5/day). A daily run costs about $0.45–0.60 per story.
