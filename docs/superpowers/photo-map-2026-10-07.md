## 4. Open questions this map raised (for Tommy, not decided here)

1. Article-photo rule 3 needs to know which subject a **slide** is about. Today only the Writer's IMAGE line carries that. Does the rewrite take it from the Writer's request, or from the subjects named in the slide's text, as the cover does now with `subjectsNamedIn`?
2. "Lead image" (§3 rule 1): is og:image the lead image, or the first `<figure>`? Today's Writer filter prefers figures and drops og:image when a figure exists. An og:image has no caption, so under rule 2 it is usable only as an official image.
3. A quote slide whose speaker has no headshot: today the Writer may write it with IMAGE `none`. The spec says that quote becomes a regular story slide instead. That changes which slide type the Writer picks, not only its IMAGE line. Is it inside the IMAGE-rule rewrite (spec §7), or does it reopen the frozen Writer?
