## Anti-Patterns Verdict

**LLM assessment:** Not slop. Passes the product test (Linear/Stripe-trustworthy): no gradients, eyebrows, side stripes, glass or hero-metric template; orange held for actions/focus/Needs you; type always dot + icon + name. Residual tells: four identical idea-pool cards; 5-up photo card grid (fine for media).

**Deterministic scan:** CLI `detect.mjs` over 72 hub files (tsx + css): 0 findings, verified not suppressed (seeded control produced 8). Browser overlay on 5 pages × 2 widths: raw counts 59–281 per page, almost all false positives — tiny-text on Next RSC `<script>` nodes (body inherits the 10.56px root; visible text never < 12px), thin-border-wide-shadow on closed confirm dialogs (documented Overlay elevation), cramped-padding on padless `.sh-panel` (rows carry the padding), Roboto (locked brand body font). True positives: `.sh-note` capped at 90ch vs DESIGN.md's 70ch; heavy ellipsis on `.sh-item__name` at 390px and on photo credits. No page errors, no horizontal overflow at 390.

**Agreement:** both flag phone truncation. The detector cannot see state logic; the review caught the contradictions and the dead-end signals.

## Overall Impression

A calm, coherent control room with a real drill model. The biggest gap is honesty under the current flags-off state: the loudest signal ("28 need you") points at rows nobody can act on, and a few states contradict each other.

## What's Working

1. One state language (`views/state.ts`, StateBadge/TypeMark) renders a post identically everywhere; only Needs you and Failed carry color.
2. Drill without losing place: intercepted-route `<dialog>` drawer, focus returns to the row, crumbs keep the trail, deep-linkable day sheet, compare tray persists.
3. Numbers carry comparisons: "0.4× typical", KPI deltas + sparklines, dashed typical curve, cost beside metrics.

## Priority Issues

**[P1] The loudest signal points at dead ends while flags are off.** "28 need you" in orange includes Older 8 and Later 13; Carousel rows show countdowns with no path; the day sheet's "Schedule something here" opens into an off note. Fix: split the count into actionable vs waiting, drop Older from the orange count, quiet badge for un-actionable rows sorted after actionable, hide Schedule-here while scheduling is off. (/impeccable clarify, /impeccable harden)

**[P1] State contradictions erode trust.** "Scheduled · Slot passed"; an open slot listed beside a post scheduled in that window (`dayPlan` trusts slot id over publishAt); pool "#1 · Rank 3"; same title shown as needs-approval and scheduled with no disambiguator. Fix: an overdue state, derive windows from publishAt, one rank, disambiguate collisions. (/impeccable harden)

**[P1] Phone is shrunken desktop.** Tables scroll inside 356px wrappers (ranked column off-screen), pool titles cut to ~12 chars, charts hover-only ("Hover for a day's numbers"), 21px name links and 30px buttons. Fix: stacked rows under 720px, pointer/tap charts, 44px touch targets. (/impeccable adapt)

**[P2] Calendar spends ink on the predictable.** Heat shading looks like out-of-month gray, legend incomplete, future weeks are identical 6–8px rings (color-only type), summary has no comparison. Fix: exceptions-only future days, distinct out-of-month, complete legend, vs previous month. (/impeccable distill)

**[P2] "What's working" doesn't answer.** ±15% band makes every group "about typical"; bar scaled to 2× median with no median mark; internal factor names. Fix: lead sentence, signed % vs median, median tick, one-line factor gloss. (/impeccable clarify)

## Persona Red Flags

**Alex (power user):** no shortcuts, 2–3 tab stops per row, no batch approve, no prev/next day.
**Sam (accessibility):** hover-only chart values; month grid uses role=grid without arrow keys (~35 tab stops); focus ring #ff5e1a on #fafafa ≈ 2.9:1 (< 3:1); color-only calendar marks for sighted low-vision users; "Waiting on you, above." relies on position.
**Casey (phone):** ranked metric off-screen, small targets, top-right Close, "Hover" copy on touch, truncated pool titles.
**Tommy (morning operator):** can't separate actionable from stale; Carousel countdowns with no path; "Refilled 49 days ago" not flagged; "Slot passed" forces a trip to logs.
