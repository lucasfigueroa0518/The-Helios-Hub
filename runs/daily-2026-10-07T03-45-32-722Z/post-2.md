## Caption

Anthropic has put Claude for Google Workspace, an add-on for Google Docs, Sheets and Slides, into public beta on all paid Claude plans. It also released new beta connectors that let Claude create and edit Google files from the Claude chat, Anthropic says.

Anthropic says the add-on opens in a sidebar beside the file, reads it and can edit it directly. By default each edit waits for the user’s approval, and some actions, such as adding a link or removing access, always pause. Google’s own Gemini is already built into Workspace, and 9to5Google frames the Claude add-on as useful for people already invested in Claude. Anthropic lists beta limits, including a six-minute cap on a single operation and no Firefox support. Most of the capability and security claims come from Anthropic, and the sources opened had no independent testing.
