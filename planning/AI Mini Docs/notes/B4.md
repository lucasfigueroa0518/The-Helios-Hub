# B4 notes: media kit + render (2026-10-28)

## Decisions
- **Kit** `explainers/reel-ai-drama/kit/` is a fork of the news kit. It has no sting, takes any number of frames, and the last frame is the brand close. Frame modules export `{ treatment, build, render }`; `ground` is gone, and try checks `treatment` against the storyboard. `ctx` gains `treatment` and `media` (from `assets/inventory.json`).
- **Close** lasts 2.5s and is code-built: the "Reel AI Drama" wordmark, "a Helios series" and the Helios mark, set below the caption band. The question is the close's voiceover and is captioned, so QUIET stays empty. pace keeps the close at 2.5s. A question longer than 2.3s stretches it to the voice length + 0.2s, and try warns.
- **Silent beats.** A frame with no voiceover keeps its planned length, clamped to 0.6–4s. Cold-open tempo is natural (1.0, not Real Case's 1.2).
- **Captions** use `presets/reel-ai-drama/caption-skin.html`, the Explainer skin with paper-lit text and a soft shadow on dark grounds and ink on the whiteboard. Every treatment except the whiteboard counts as dark. The newspaper page starts at y 600, so the captions sit on the desk.
- **Music** (`music.mjs`): cues `start | change | drop | hold | end` on storyboard frames. Each `change` picks the next track in the style rotation. A `start` after a `drop` brings the same track back. The bed fades out across the close. `choice.json` now has `ids[]`.
- **Sound** (`sound.mjs`): new kind `ambience` (`what`, `dur` 0.5–30s), for D-47.
  - The library has **no ambience recordings**, so beds are procedural ffmpeg noise: room, office, machines, street, wind, rain, hall. These are honest room tones; a crowd murmur is only approximated. **Ask Lucas** about importing CC0 room tones and city beds.
  - D-48: a foley or ambience whose `what` names an event (applause, siren, door, shutter…) must carry `shown: <asset id>`, or try fails it.
- **Workspace** lives in `<jobsRoot>/<jobId>/render/{project,home}`, because the Explainer prepare wipes its own job folder. The harvest's `<jobsRoot>/<jobId>/media/` survives, and `ws.jobDir` is `<jobsRoot>/<jobId>`. **B5:** the `_harvest` copy dance is no longer needed, but it is harmless.
- **writeProjectFiles** finds `asset.file` under `mediaRoot` (if given), then the project's parent, then its grandparent. It copies sibling sidecars `<stem>.*` and returns `{ frames, media, missing, problems }`. It adds a close when the plan has none.

## Formats agreed with B2
- **Boxes:** `media/V7.boxes.json` = `{ image?, width, height, boxes: [{ text, x, y, w, h }] }` in image pixels, which is B2's format, also named by the flag `boxes:<path>`. Boxes are rescaled when the sidecar's `width` ≠ `asset.width`. Each one is inlined as `ctx.media.V7.boxes`.
- **Maps:** `renderMap({ lat, lon, zoom, label, sublabel, out })` writes three files:
  - `out`: the map with pin and label (a usable still);
  - `<stem>.plain.<ext>`: the same map without them;
  - `<stem>.map.json`: `{ lat, lon, zoom, label, sublabel, width, height, pin:{x,y}, plain }`.
  - A `.jpg` `out` gives ~0.7MB files instead of ~6MB PNGs: **B2, prefer `.jpg`**. The `map` treatment drops the pin and label itself.
- **Parallax** (optional): `<stem>.fg.png` (the subject cut from the same photo) and `<stem>.plate.<ext>` (inpainted) → `ctx.media.Vn.cutout.{fg,plate}`.

## Answers to B5
- **Q4 (rewrite after voice):** writeProjectFiles rewrites STORYBOARD.md with estimated durations, so call `repace(projectDir)` after it. That runs pace from the existing voices, with no model and no HeyGen. This is valid only if every frame keeps its number and spoken words. Check with `sameVoices(before, after)`; if false, run `runVoice` again.
- **Q6 (transcript):** `renders/contact-sheet.txt` sits beside `renders/contact-sheet.png`. It holds frames with times and treatments, then the caption pages as the skin shows them, then the still times. `captionTranscript(projectDir)` returns the same text.
- `assembleProject(projectDir, { heygenApiKey, music }, deps)` returns `{ ok, problems, warnings }`. `warnings` are pacing notes (length outside 55–80s, frames over 8s, a long close question).
